Llaves para las notificaciones de avisos

Esta página crea, en tu navegador, el par de llaves con el que Conoxxo firma las notificaciones. Nada se manda a ningún servidor: las llaves solo existen en esta pantalla hasta que las pegues en Cloudflare.

Hazlo una sola vez. Si después generas otras, cada celular tiene que volver a activar los avisos.
Dónde pegarlas
  1. Cloudflare → Workers & Pages → conoxxo → Settings → Variables and Secrets.
  2. Add → tipo Secret → nombre VAPID_PUBLIC_KEY → pega la primera.
  3. Add → tipo Secret → nombre VAPID_PRIVATE_KEY → pega la segunda.
  4. Deploy. Luego cierra esta página.
